# Элиас

Игра в объяснение слов для одного телефона. Flutter, Android (iOS собирается из того же кода на macOS).

## Сборка

```bash
flutter build apk --release --split-per-abi   # APK в build/app/outputs/flutter-apk/
```

Готовые APK лежат в `dist/` (`Elias-arm64.apk` — для почти всех современных телефонов).

## Словари

- Исходники: `words_raw/<категория>.txt` — строго одна карточка на строку; запятые внутри названий сохраняются.
- `python3 tool/clean_words.py` чистит их (только кириллица, без дублей) и кладёт в `assets/words/`.
- Новая категория: файл в `words_raw/` + строка в `lib/categories.dart`.

## Код

- `lib/state.dart` — настройки, партия, колода, подсчёт очков.
- `lib/screens/` — экраны: меню, категории, табло, ход, итоги, победа.
- `tool/make_icon.py` — иконка приложения.
- `flutter test test/logic_test.dart` — тесты логики; `test/screens_test.dart` рендерит экраны в `test/shots/`.

## Исправления 0.1.1

- Незавершённый ход, последнее слово и исправления итогов сохраняются. При восстановлении таймер на паузе.
- Время сохраняется при ответах/паузе/сворачивании и раз в секунду. При аварийном убийстве процесса возможен откат последней секунды; запись в хранилище асинхронная.
- Нельзя снять последнюю категорию; запуск с пустой колодой запрещён.
- Истечение времени во время вылета карточки не выдаёт новую карточку для общего последнего слова.
- Ничья при ручном завершении отображается как ничья; завершённая партия восстанавливается как результат.
- Состав команд фиксирован на партию. Для изменения нажмите «Сбросить партию и изменить команды».
- Счётчики показывают уникальные слова (регистр и е/ё не создают дополнительные карточки).
- Убраны верхние пределы времени, цели и количества команд; минимум — 10 секунд и 2 команды.
- Проверки: `flutter analyze`, `flutter test` (включая регрессионные проверки и детерминированные скриншоты).

Для совместимости с установленной 0.1.0 APK пока подписывается тем же отладочным ключом. Перед публичной публикацией настройте постоянный ключ подписи; смена ключа потребует удаления старого приложения у пользователей, если не настроен поддерживаемый механизм миграции подписи.

## Словари и баланс 0.1.2

- 28 категорий: 11 640 записей, 9 601 уникальная карточка. Обычный набор — 8 563 уникальные карточки.
- «Сложные слова» по умолчанию выключены. Переключатель добавляет размеченные вручную редкие термины и имена, а не определяет сложность по длине слова. Разметка субъективна и редактируется в `tool/word_levels.json`; одна и та же форма слова может иметь разную сложность в разных категориях.
- Детский набор: 524 карточки, все обычные. Уменьшительные дубли сокращены, добавлены повседневные предметы и понятия.
- Исправления и удаления записаны в `tool/word_edits.json`. Персонажи убраны из «Знаменитостей», социальные статусы — из «Профессий».
- В смешанной колоде категории чередуются случайными кругами: по одной карточке от каждой непустой категории. Когда слова одной темы исчерпаны, остаются другие; повторы начинаются только после исчерпания всей выбранной колоды.
- Исходники `words_raw/*.txt` теперь построчные. Сборщик больше не делит названия по запятым и не выбрасывает ошибки молча: при недопустимой карточке или дубле он останавливается до изменения ресурсов.
- `python3 tool/clean_words.py` пересоздаёт TXT и `assets/words/advanced.json`; `--check` проверяет соответствие без записи.
- `python3 -m unittest discover -s tool/tests` проверяет словари и экспорт; `flutter test` проверяет фильтрацию, баланс выдачи, сохранение настройки и остальную игру.
- При обновлении незавершённая партия из старой версии сохраняет прежний полный набор. Сложность можно переключить после окончания текущего хода.
