Ты составляешь словари для русской настольной игры «Элиас» (Alias): игрок объясняет слово, не называя его.

Для КАЖДОЙ категории из своего списка создай файл words_raw/<id>.txt:
- одно слово (или устойчивое словосочетание) на строку, без нумерации, без комментариев, без пустых строк;
- ТОЛЬКО русский язык, кириллица, нижний регистр (кроме имён собственных — их с заглавной);
- существительные в именительном падеже, единственном числе (кроме категории actions — там глаголы в инфинитиве);
- по возможности одно слово; словосочетания до 3 слов допустимы только если иначе нельзя (имена людей, названия фильмов, городов, блюд и т.п.);
- без повторов внутри файла, без слишком редких/непонятных слов, без мата и пошлости;
- смешивай лёгкие и сложные слова, все слова должны быть понятны обычному взрослому носителю русского языка;
- МИНИМУМ 400 строк в каждом файле (лучше 450–500). Это важно: нужен ОГРОМНЫЙ список. Пиши файл частями, если нужно, потом проверь количество строк (wc -l) и добавь, если меньше 400.

Не создавай и не трогай никакие другие файлы. В конце ответь списком созданных файлов с количеством строк.
